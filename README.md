# 시연이의 미션 체크

설치 없이 브라우저에서 바로 사용하는 개인 미션 체크 프로그램입니다.

## 실행 방법

`index.html` 파일을 더블 클릭해 브라우저로 열면 됩니다.

## 기능

- 오늘의 미션 추가, 완료 체크, 삭제
- 완료율과 누적 왕관 표시
- 하루 미션을 모두 완료하면 왕관 1개 지급 및 누적 보관
- 왕관 100개마다 엄마아빠와 데이트권 지급 및 특별 축하
- 날짜가 바뀌면 완료 체크 자동 초기화
- 어제 미션의 체크 상태와 책·영상 제목을 확인하고 수정
- 브라우저의 로컬 저장소에 기록 자동 저장
- 기본 미션 구성: 한글독서·영어책 청독·낭독스쿨 2종(각각 체크)·영어영상·수학
- 낭독스쿨은 2026년 8월 9일까지 입트영·영초탈, 8월 10일부터 영초탈·전래동화로 자동 변경
- 수학 미션은 수·토·일요일 `쎈수학`, 나머지 요일 `쎈연산`으로 자동 변경
- 개학 후 화요일은 한글독서·영어책 청독·쎈연산·영초탈·전래동화, 수요일은 쎈수학만, 목요일은 한글독서·영어책 청독·영초탈·전래동화로 구성
- 월~금에는 학교숙제, 월·수에는 영어학원숙제를 추가
- 요일별 미션 미리보기로 실제 기록을 바꾸지 않고 월~일 구성을 확인
- 날짜별 결과를 모아 기존 달마고치 양식 기반 한달보고서 자동 집계
- 보고서 연결: 영어책 청독 → 영어책, 영어영상 → 영상, 한글독서 → 마주이야기
- 한글독서·영어책 청독·영어영상의 제목을 날짜별로 기록
- 입력한 책·영상 제목을 한달보고서의 해당 관찰 영역에 날짜 없이 순서대로 자동 누적
- 한달보고서에 같은 제목이 반복 입력되면 처음 한 번만 표시
- 미션체크 화면에서 월~토 학원 스케줄 확인 및 오늘 일정 강조
- Supabase 로그인으로 휴대폰·PC 기록 자동 동기화
- 최신 기록 비교, 실시간 반영, 마지막 동기화 시각 및 수동 재동기화 지원
- 휴대폰 홈 화면 설치와 기본 오프라인 실행을 지원하는 PWA
- 월별 관찰 메모 저장 및 A4 인쇄/PDF 저장
- 엄마·아빠·시연이 함께 쓰는 월별 사랑편지와 한달보고서 자동 누적

> 로그인 전 기록은 현재 브라우저에 저장되며, Supabase 계정으로 로그인하면 같은 계정을 쓰는 기기끼리 동기화됩니다.
