# 시연이의 미션 체크

설치 없이 브라우저에서 바로 사용하는 개인 미션 체크 프로그램입니다.

## 실행 방법

`index.html` 파일을 더블 클릭해 브라우저로 열면 됩니다.

## 기능

- 오늘의 미션 추가, 완료 체크, 삭제
- 완료율과 별 점수 표시
- 하루 미션을 모두 완료하면 왕관 1개 지급 및 누적 보관
- 최근 7일 도장판과 연속 달성일 표시
- 날짜가 바뀌면 완료 체크 자동 초기화
- 브라우저의 로컬 저장소에 기록 자동 저장
- 매일 기본 미션: 한글독서·영어책 청독·낭독스쿨·영어영상·수학
- 수학 미션은 수·토·일요일 `쎈수학`, 나머지 요일 `쎈연산`으로 자동 변경
- 날짜별 결과를 모아 기존 달마고치 양식 기반 한달보고서 자동 집계
- 보고서 연결: 영어책 청독 → 영어책, 영어영상 → 영상, 한글독서 → 마주이야기
- 한글독서·영어책 청독·영어영상의 제목을 날짜별로 기록
- 입력한 책·영상 제목을 한달보고서의 해당 관찰 영역에 날짜 없이 순서대로 자동 누적
- 미션체크 화면에서 월~토 학원 스케줄 확인 및 오늘 일정 강조
- Supabase 로그인으로 휴대폰·PC 기록 자동 동기화
- 휴대폰 홈 화면 설치와 기본 오프라인 실행을 지원하는 PWA
- 월별 관찰 메모 저장 및 A4 인쇄/PDF 저장

> 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 삭제하면 기록도 사라집니다.
