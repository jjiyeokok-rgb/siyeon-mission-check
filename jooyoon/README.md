# 주윤이의 미션 체크

시연이 버전과 별도 주소·별도 저장 공간을 사용하는 하늘색 미션 체크 앱입니다.

## 기본 미션

- 매일: 한글책읽기, 재능 학습지, 영어영상
- 월요일: 터전
- 화요일: 터전, 놀이방
- 수요일: 터전
- 목요일: 터전, 나래울, 하키
- 금요일: 터전, 재능
- 토요일: 하키, 오프아이스
- 일요일: 추가 요일 미션 없음
- 2026년 8월 3일 월요일 예외: 터전, 나래울

## 클라우드 연결

Supabase SQL Editor에서 `cloud-table.sql`을 한 번 실행하면 기존 부모님 계정으로 로그인해도 시연이 기록과 섞이지 않고 별도로 동기화됩니다.
